# 📂 Código-Fonte da Aplicação Web — Café & Aconchego

Este diretório contém o código-fonte completo da aplicação web responsiva desenvolvida sem o uso de frameworks CSS, utilizando **HTML5**, **CSS3 (Puro)** e **JavaScript**.

---

## 🛠️ Arquivos do Projeto

* `index.html` — Estrutura de marcação principal e layout das páginas/abas da aplicação.
* `style.css` — Folha de estilos personalizada com tema visual da cafeteria, variáveis CSS e design responsivo.
* `script.js` — Lógica de interatividade, controle de navegação por abas, validação e envio de formulários, além da geração de comprovantes.
